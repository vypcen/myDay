# myDay

Календарь, где у каждого дня есть свободный холст: заметки, задачи, картинки, аудио и любые файлы.
Работает как устанавливаемое веб-приложение (PWA) — на компьютере и телефоне, без интернета.

## Управление

| Действие | Мышь | Сенсорный экран |
|---|---|---|
| Двигать холст | зажать фон и тянуть, колёсико | тянуть пальцем по фону |
| Масштаб | Ctrl + колёсико, кнопки −/+ | щипок двумя пальцами |
| Меню добавления | правый клик по фону | долгое нажатие на фон или кнопка «+» |
| Меню элемента | правый клик по элементу | долгое нажатие на элемент |
| Новая заметка | двойной клик по фону | двойной тап по фону |
| Переместить элемент | тянуть за шапку или саму картинку/файл | то же пальцем |
| Порядок слоёв | панель слоёв (L), тянуть за ⋮⋮ | то же пальцем |
| Сменить месяц | стрелки ‹ › или ← → | свайп влево/вправо по календарю |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z, кнопки ↶ ↷ | тап двумя / тремя пальцами, кнопки ↶ ↷ |
| Выделить несколько | Shift + рамка, Shift + клик, Ctrl+A | кнопка ⬚ и рамка пальцем |
| Сгруппировать | Ctrl+G (разгруппировать — Ctrl+Shift+G) | «Действия» → «Сгруппировать» |
| Рисовать | кнопка ✎ или P | кнопка ✎; Apple Pencil рисует сразу, палец двигает холст |
| Поиск | Ctrl+K или / | кнопка ⌕ |

## Возможности

- **Холст дня:** заметки, задачи, картинки, файлы, аудио, голосовые заметки, фото с камеры, рисунки, стикеры
  (стикеры iPhone и Mac, вырезанные из «Фото» объекты, эмодзи).
- **Оформление любого элемента:** фон (10 цветов темы, «без фона» или свой цвет), рамка (толщина, цвет,
  пунктир/точки/двойная), углы, тень, прозрачность. Шрифт и размер для заметок.
- **Слои и группы:** порядок, скрытие, блокировка; группа двигается и выделяется целиком.
- **Отмена и повтор** всех действий на холсте.
- **Поиск** по всем дням с переходом к найденному элементу.
- **Задачи:** перенос незавершённых на завтра, общий список незавершённых, перенос просроченных на сегодня.
- **Шаблоны дня:** «План дня», «Дневник», «Ретро недели», «Встреча» и свои.
- **Отметки дня:** настроение, цвет дня, трекер привычек с сериями — всё видно в календаре.
- **«В этот день»:** записи месяц и годы назад.
- **Замок:** PIN-код или пароль, Face ID / Touch ID, шифрование данных на устройстве, автоблокировка.

## Главный принцип: данные только у пользователя

- Все записи и файлы хранятся в браузере на устройстве (IndexedDB). На сервер не уходит ничего.
- Сервер раздаёт только сами файлы приложения — как обычный статический сайт. Ни аккаунтов, ни базы, ни аналитики.
- Политика безопасности в `index.html` (`Content-Security-Policy: connect-src 'self'` и др.) запрещает
  приложению обращаться к любым внешним адресам. Шрифты лежат в `fonts/`, библиотек с CDN нет.
- Бэкапы шифруются паролем на устройстве до сохранения. Без пароля их не открыть никому.

## Запуск

Любой статический сервер из корня проекта:

```bash
python3 -m http.server 8080      # или: npx serve .
```

Откройте http://localhost:8080. Открыть `index.html` двойным кликом нельзя — модули и офлайн-режим
требуют http(s).

## Публикация

Подойдёт любой статический хостинг с HTTPS: Cloudflare Pages, GitHub Pages, Netlify, свой nginx.
Сборка не нужна — загрузите папку как есть.

Перед выкладкой новой версии поменяйте `VERSION` в `sw.js` — тогда у пользователей появится
предложение «Доступна новая версия · Обновить». Данные при обновлении не трогаются.

Совет по приватности: выключите на хостинге журналы доступа или храните их минимально — тогда даже
IP-адреса посетителей не будут копиться.

## Как защищены данные от потери

| Что | Как работает |
|---|---|
| Защита от автоочистки | Приложение запрашивает у браузера постоянное хранилище (`navigator.storage.persist()`). Статус и кнопка — в панели «Бэкап». |
| Установка | В панели есть кнопка «Установить приложение» (Chrome, Edge, Android) и подсказка для iPhone. Установленным приложениям браузеры почти всегда дают постоянное хранилище, а Safari перестаёт стирать данные через 7 дней без открытия. |
| Ручной бэкап | «Скачать бэкап» — один зашифрованный файл `.myday` со всеми днями, файлами и настройками оформления. |
| Автобэкап в папку | Chrome/Edge на компьютере: пользователь выбирает папку, приложение само пишет туда копии после изменений (не чаще раза в 2 часа). Можно выбрать папку облака (iCloud Drive, Dropbox, Яндекс Диск) — облако получит только шифротекст. |
| Ротация копий | Все копии за 2 дня, по одной в день за 2 недели, в неделю за 2 месяца, в месяц за 2 года. Пустые данные в автобэкап не пишутся, так что случайное удаление не затрёт историю. |
| Напоминания | Если бэкапа не было больше недели — плашка в календаре и жёлтая точка на кнопке «Бэкап». |
| Замок приложения | PIN-код или пароль; дни, файлы, привычки и свои шаблоны хранятся зашифрованными (AES-256-GCM, ключ данных завёрнут ключом из PIN через PBKDF2, 600 000 итераций). Face ID / Touch ID — через WebAuthn PRF, если устройство поддерживает. Забытый код не восстановить — только бэкап. |
| Восстановление | «Объединить» (более свежая версия дня побеждает) или «Заменить всё» с подтверждением. |
| Несколько вкладок | Вкладки синхронизируются через BroadcastChannel; автобэкап запускается только в одной (Web Locks). |

## Формат бэкапа `.myday` (версия 1)

Бэкапы прежних версий (`.tetrad`) — тот же формат и открываются как обычно.

```
"TETRADBK" | версия (1 байт) | длина заголовка (u32 BE) | заголовок JSON {kdf, iter, salt, np}
затем блоки по 4 МБ: флаг (0 — обычный, 1 — последний) | длина (u32 BE) | шифротекст AES-256-GCM
```

- Ключ: PBKDF2-SHA256, 600 000 итераций, соль 16 байт.
- Nonce блока: 8 случайных байт бэкапа + номер блока. AAD: SHA-256 заголовка + номер блока + флаг —
  подмена, перестановка и обрезка блоков обнаруживаются.
- Внутри: манифест JSON (дни, настройки, список файлов) и байты файлов подряд.
- Открытым остаются только параметры шифрования и общий размер файла.

Ключ для автобэкапа хранится на устройстве как неизвлекаемый `CryptoKey`: пароль не хранится нигде,
а прочитать сам ключ нельзя даже скриптом.

## Ограничения, о которых стоит знать

- Забытый пароль бэкапа не восстановить — это цена анонимности. Интерфейс предупреждает об этом.
- Синхронизации между устройствами нет: перенос — через бэкап и «Объединить».
- Бэкап и восстановление собираются в памяти, поэтому архивы на несколько гигабайт на слабых телефонах
  могут не пройти. Для таких объёмов следующий шаг — потоковая запись в нативной обёртке.
- Автобэкап в папку есть только в браузерах на Chromium на компьютере; в Safari и Firefox — ручной бэкап
  и напоминания.

## Структура

```
index.html            разметка и политика безопасности
css/app.css           стили, css/fonts.css — локальные шрифты (SIL OFL 1.1)
js/app.js             интерфейс: календарь, холст, слои, оформление, панель бэкапа
js/db.js              хранилище IndexedDB
js/backup.js          шифрование, формат .myday, восстановление, автобэкап и ротация
js/vault.js           замок приложения: шифрование данных на устройстве, PIN, Face ID / Touch ID
sw.js                 офлайн-кэш файлов приложения (данные пользователя туда не попадают)
manifest.webmanifest  установка как приложение
```
